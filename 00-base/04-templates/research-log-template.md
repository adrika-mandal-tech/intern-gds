### What counts as a "found"

Anything you did not know when you sat down. It does not have to be a result:

- "Betweenness on `facebook_combined` takes 86 s, which is twice `ca-GrQc`
  despite being a smaller graph"
- "The first timed call is 270× slower — `runs.timed` already handles this, I
  was about to write my own timing loop and would have got it wrong"
- "Louvain returned 31 communities one run and 28 the next on identical input"
- "Spent two hours on X, still do not understand it"

That last one is a legitimate entry. A session with nothing found is a real
session and should be logged as such — but if you get three in a row, that is a
signal to ask for help rather than a reason to write nothing.
